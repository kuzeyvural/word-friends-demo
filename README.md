# Word Friends Demo

Bu repo, arkadaşlar arasında kelime paylaşımı yapan örnek bir demo sitenin statik HTML/CSS/JS sürümünü içerir.

## Çalıştırma

Tarayıcıda `index.html` dosyasını açmak yeterlidir.

## GitHub Pages ile yayınlama

1. GitHub'da bu repo'yu aç.
2. `Settings` -> `Pages` -> `Deploy from a branch`
3. Branch olarak `main` seç.
4. Folder olarak `/ (root)` seç.
5. Kaydet.
6. GitHub sana sitenin URL'ini verecektir.

Örnek URL formatı:
`https://<kullaniciadi>.github.io/word-friends-demo/`

## Not
Bu demo gerçek kullanıcı girişi veya veritabanı içermez; sadece arayüz ve örnek etkileşimler gösterir.
